# Javin's Digital Portfolio

A premium, high-performance digital portfolio for **Oreoluwa Ifedinma Chiazor**, built with a focus on simplicity, accessibility, and high-end aesthetics.

## Professional focus

I am a **Mobile and Web Developer** and **Startup Architect** dedicated to bringing ambitious ideas to life. This portfolio is designed to bridge the gap between technical execution and business strategy, making my value clear to both technical and non-technical stakeholders.

## Key Features & Highlights

- **Standardized Messaging**: Replaced technical jargon with outcome-oriented language.
- **Startup Architect Card**: A visual redesign of the About section focusing on product lifecycle and business impact.
- **Proven Results**: Highlights major milestones, including achieving a **#1 Google Search ranking** for core platforms.
- **Glassmorphic Design**: A premium, modern UI built with Tailwind CSS and Framer Motion.
- **Responsive & Optimized**: Blazing fast performance powered by Vite.

## Tech Stack

- **Frontend**: React 18, Tailwind CSS, Framer Motion
- **Icons**: React Icons (Feather & Simple Icons)
- **Tooling**: Vite
- **Deployment**: Vercel

## Project Structure

```
src/
├── components/          # Reusable UI sections
│   ├── Hero.jsx         # Accessible headline & product focus
│   ├── About.jsx        # Startup Architect visual card
│   ├── Skills.jsx       # Services & Expertise
│   ├── Projects.jsx     # Case studies & highlights
│   ├── Experience.jsx   # Career milestones (Skholar, Syntax)
│   ├── Contact.jsx      # Lead generation & connections
│   └── Footer.jsx       # Final branding & social links
```

## Getting Started

1.  **Install dependencies**: `npm install`
2.  **Run development**: `npm run dev`
3.  **Build for production**: `npm run build`
